# ATM System

A Java-based ATM system developed as part of the ICS4U Computer Science course at Sunway College.

## 📌 About

This project simulates a basic ATM banking system. Users can interact with the system through a menu-driven interface to perform common banking operations.

The project was developed to practice Java programming, object-oriented programming, file handling, and data management.

## ✨ Features

* User account management
* Account balance checking
* Deposits and withdrawals
* Money transfers
* ATM menu interface
* Transaction processing
* Data storage and retrieval

## 🛠️ Technologies

* Java
* Object-Oriented Programming fundamentals
* Classes and Objects
* Methods
* Arrays
* Scanner for user input

## 🎯 Learning Objectives

Through this project, I practiced:

* Designing programs using multiple Java classes
* Working with objects and methods
* Managing and processing user data
* Reading data from external files
* Writing menu-driven programs
* Handling user input and program flow
* Organizing a larger Java project into multiple components
